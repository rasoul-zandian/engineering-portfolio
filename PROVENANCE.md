# Sample provenance and publication scope

## Cadvert

The two PNG assets are selected outputs previously included in the public Cadvert showcase:

- `cadvert/assets/interior-study.png`: an interior visual study.
- `cadvert/assets/cad-model.png`: a raw CAD-derived geometry baseline.

They are independent samples, not a matched before-and-after pair. They do not certify architectural accuracy, BIM compliance or planning approval. The externally linked film is the public 960 × 540 / 24 fps preview, not the 1080p benchmark export. The montage workspace and film remain linked through the existing public showcase.

The benchmark described in the Cadvert case study is a recorded local observation: one run per profile on Apple M2 / 8 GiB, excluding network downloads and measuring FFmpeg child-process RSS. It is not an SLA or total-system memory measurement.

## Elite

Only a high-level case study and a newly invented JSON illustration are included. The JSON does not reproduce a private API contract or record. No source code, internal operating instructions, role matrices, deployment endpoints, customer data, employee information or internal screenshots are included.

## Repository boundary

This repository was assembled independently as a new documentation-only Git history. No private repository history was imported. The underlying products are not distributed here. Project names identify the case studies; this portfolio does not grant rights to private software or third-party materials.

Content reviewed for publication on 10 November 2026. Application test suites and live production readiness were not revalidated as part of this publication.
